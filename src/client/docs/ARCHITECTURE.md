# 前端架构

`AuthGate` 提供 Session context；`Layout` 负责固定页眉、导航、账号菜单、主题及独立滚动内容区。`QuickSearch` 搜索人员与任务。`App` 保留旧路由兼容，首页渲染 SchedulePage。

`Modal` 统一侧栏与对话框，使用 portal、顶层窗口栈、inert、焦点循环及关闭后恢复焦点。嵌套配置不得让底层窗口处理 Escape。

`WorkComposer` 只提交 `/work`，服务端原子创建任务和全部重复班次。班次候选始终请求 `/preview`；正式分配单独确认。批量预览显示整个任务当前各班次缺口和候选数量，确认时服务端逐次检查，预览不承诺最终人数。

`ModelsPage` 读取 `/admin/model-config` 快照，所有新增、启停、删除、密钥替换和排序仅写当前组件内存草稿。保存栏显示未保存状态，点击保存后一次 PUT 整页配置；失败保留草稿，放弃更改重新读取服务端。未应用的添加或密钥输入会阻止保存，避免漏存。保存期间禁用编辑。已有模型可随时测试已保存配置，测试按模型 ID 独立管理 pending/result，不使用全局 busy，不阻塞其他测试、编辑、排序、删除或保存。新增模型需先保存。测试结果留在对应卡片下，并注明测试时的已保存配置。密钥不进入浏览器持久化；API 只返回 hasKey。

排序使用 @dnd-kit 的 PointerSensor、KeyboardSensor、SortableContext 和 DragOverlay；仅 44px 抓手启动拖动，其他区域仍可滚动/选字。相邻条目用 280ms transform 弹性让位，放下动效同速；新草稿行用 220ms 入场。系统减少动态效果时取消空间动画。保留上移/下移按钮和中文读屏提示。beforeunload、hash 路由和管理 tab 切换在有草稿时提醒放弃。

页面状态与网络状态通过现有 useAsync 管理。日期范围保存在 sessionStorage；侧栏操作保留底层页面筛选和滚动上下文。明暗主题保存在 localStorage。没有引入新路由框架或组件框架。

## 浏览器 Agent 导入

`agent-import/` 实现本地工具、IndexedDB 检查点和自主工具循环，`ImportsPage` 替换原课表/人员 tabs。组织树展开人员课表与任务班次，支持来源/推断、自然语言反馈、字段编辑和按人员排除。关闭/刷新暂停，恢复前核对正式数据和租约；完成/取消 8 小时后清理本地材料。`PersonalTimetable` 在人员课表页提供实际时间显示和修正入口。人员资料支持班级/专业。

文档与 WASM 仅在本地处理，模型凭据代理位于 Worker；新流程不调用旧模板解析器。格式能力与边界见根目录 `docs/AGENT_IMPORT.md`。专项验证 `pnpm test:agent-browser` 使用真实浏览器工具及拦截模型响应；不等同真实模型识别验收。

`shared/agent-import/context.ts` 提供活动上下文预算、图片引用替换与停滞状态；`store.ts` 通过原草稿库的待归档检查点连接独立历史库，归档幂等可重放。`runtime.ts` 在摘要归档后才替换活动上下文，读两份新材料后要求持久识别成果。`HistoryPanel.tsx` 按需分页展示完整证据，不把所有历史放入活动模型请求。模型临时故障最多重试一次，业务提交不自动重试。模型超时时将缩小输出的引导写入活动上下文与检查点，重试及刷新恢复均要求单人分段保存；这只约束输出大小，不代替 LLM 业务判断。

### 导入实际材料回归修正

`Job.timetables` 保存每人结构化方案和来源；append、绑定与人工修订通过 `stageTimetable` 在克隆草稿上校验后替换，避免失败留下半份关系。课表图像读取和 OCR 共用增量保存检查点；未记录成果时保留整图及最近局部图，不交接丢失。目录名也可以作为可验证的来源。编码读取、OCR 不解析业务字段。OCR 静态依赖由 `scripts/prepare-ocr.mjs` 从锁定包复制，运行时同源加载。

`verification.ts` 为同一 Agent 保存逐人复核的独立活动上下文、主任务对话、来源页覆盖与方案签名。完成当前人的保存后先回看原件，再允许读取下一人；核对可刷新恢复。`checkpoint` 模式收窄可用工具以先持久化已读成果。人工编辑同步方案与正式结构草稿，避免后续绑定覆盖修订。

文件完整性采用基础坐标覆盖：表格不能漏列，文本不能跳段，图片不能只读局部。`sheet-image.ts` 使用 html-to-image 渲染单元格网格，`render_sheet` 支持按范围放大；不进行业务识别。

`image-payload.ts` 只在模型传输边界压缩超预算的图片预览，限制合计及单图大小；原材料、OCR 输入和持久化检查点的图片证据不改写。所有图片与来源保留，缩放后附原坐标裁剪提示，也覆盖旧版本恢复的大图上下文。

导入新增 `calendar.ts` 日历证据契约、`CalendarReview` 部分字段复核、`readiness` 全批确认签名和确定性摘要。逐人核对记录教师地点及材料完整性，旧签名需重新核对；已提交结构化记录可通过 `SavedReports` 下载。明确无固定时段课程保留个人选课，未知时段保持提交阻塞。依赖和环境变量不变，前后端工具协议需同步发布。

模型超时、输出截断或原生工具选择失败均记录明确错误类别；浏览器持久保存小批输出/工具格式纠正指令后最多重试一次。配置错误、额度耗尽及内容过滤不套用该恢复策略。私有 live 测试可用 `ROTA_CAPTURE_PROVIDER_RESPONSES=1` 保存 Vertex 候选响应到测试输出目录，用后按个人资料处理；生产不保存这些响应。

操作员直接修改生成的学期/作息时，同步其日历证据字段，再由统一逻辑生成实际占用。手工修改和排除人员仅能延续修改前有效的全批确认，不能使其他尚未核对的变化自动通过。

全批协调通过 `consistency.ts` 比较已识别的同名课程教师字段，索引与明细分页；`consistencyChecks` 保存逐项结论及字段签名，`consistencyReads` 记录新增明细读取进展，重复读取不会反复重置空转计数。`reconcile` 阶段不把已处理原件的回看误当新材料，修订课表后仍须重新逐人核对。审核页展示跨课表差异解释，未决项进入最终报告。

`reconcileTask` 将全批协调收敛为逐项活动上下文；`consistencyCoverage` 记录本轮原件覆盖，跨项复用已读原件，修订后仍触发人员复核。结论中的 `checked_variants` 必须匹配当前字段，正常任课差异还须原件覆盖完成。单批大量参数失败先返回完整工具错误并给模型修正机会，连续两批仍失败才暂停，空转限制继续生效。

差异签名与来源注释分离，字段未变的旧版已核对结论可复用；来源回看覆盖仍单独校验。全批材料提示折叠展示并精确去重，提交阻塞条件不变。

单轮请求将网络恢复预算与模型响应修正预算分离，最多三次网络退避和一次模型修正；每次失败先持久保存诊断和上下文，再等待重试。
