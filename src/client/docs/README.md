# Web 界面

React 19、Tailwind 4，原有 hash 地址继续兼容。首页直接进入排班；桌面主导航和手机底部导航只保留排班、人员、导入。管理通过桌面侧栏或账号菜单进入。

- 排班：日期/部门/名称筛选、缺员过滤、CSV 导出、安排工作、任务与公平账本视图。任务详情、候选和已安排人员在侧栏处理。
- 安排工作：同一表单填写名称、部门、日期、起止时间、人数，可按周重复。缺少学期或人员时可在侧栏补建并返回原草稿。
- 人员：点击姓名查看课表和请假；原资料编辑、部门与成员关系继续保留。
- 导入：统一材料入口，浏览器本地 Agent 整理后按组织、人员课表和任务班次复核；支持暂停恢复、来源查看和一键提交。
- 管理：规则、学期、模型服务、账号授权、审计分区。
- 模型服务：models.dev 目录、图片能力过滤、勾选模型、粘贴加密密钥、启停、测试、拖拽及按钮排序。浏览器 Agent 按全局顺序选择支持视觉及工具调用的模型，失败切换下一项；旧单文件兼容接口仍保留独立默认模型语义。

主题遵循根目录 DESIGN.md，可手动切换并保存偏好。Inter 自托管，许可证随字体分发。

## 验证

先启动隔离的本地数据服务和 `pnpm dev`，再运行 `pnpm test:browser`。浏览器测试会创建测试学期/部门/人员和班次，只可指向隔离本地数据。测试截图和报告已忽略，不进入生产构建。


### 模型配置草稿与排序

模型服务使用本地草稿与统一保存栏；新增和密钥更换先加入草稿，支持抓手/触屏/键盘排序。@dnd-kit 负责传感器、排序位置与拖动覆盖层，Tailwind 仍负责页面样式。


模型连接测试相互独立，不阻塞其他测试或配置编辑、排序、保存。测试使用已保存配置，结果位于对应模型卡片内；失败展示 HTTP 状态、上游代码/类型和可滚动的完整错误正文（敏感信息脱敏），不占用页面顶部错误区域。

## 浏览器 Agent 导入

`agent-import/` 实现本地工具、IndexedDB 检查点和自主工具循环，`ImportsPage` 替换原课表/人员 tabs。组织树展开人员课表与任务班次，支持来源/推断、自然语言反馈、字段编辑和按人员排除。关闭/刷新暂停，恢复前核对正式数据和租约；完成/取消 8 小时后清理本地材料。`PersonalTimetable` 在人员课表页提供实际时间显示和修正入口。人员资料支持班级/专业。

文档与 WASM 仅在本地处理，模型凭据代理位于 Worker；新流程不调用旧模板解析器。格式能力与边界见根目录 `docs/AGENT_IMPORT.md`。专项验证 `pnpm test:agent-browser` 使用真实浏览器工具及拦截模型响应；不等同真实模型识别验收。
