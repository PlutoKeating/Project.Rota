日期：2026-11-04。**最新整包恢复验证已进入人工复核：18 份实际课表、另 1 份缺失课表的人员提示，410 条课程方案；5,241 个已标注课程时段事实、指定教师/地点及日历断言全部通过。原件缺失的完整作息、总周数等仍待确认，因此原批次尚不满足正式提交条件。以下早期结果保留为历史记录。**

## 验收口径

使用用户提供的原始压缩包（23 个内部文件），在隔离浏览器中运行真实导入执行器、文档工具与真实供应商。业务 HTTP 写入隔离，模型配置只读。未将识别结果写入正式业务库。

对照标注来自开发 Agent 独立回看原件后的转录，不来自被测模型输出，也不等于操作员已经人工验收。比较身份、部门、课程名称及“星期 × 教学周 × 节次”的多重集合；遗漏、额外占用、重复占用均失败。无时段课程也须保存。允许的名称格式别名须逐项核对原件，不能把近义名称视为相同。

原始材料、标注、浏览器检查点及模型响应含个人资料，均保存在仓库外。复现命令与参数见 [AGENT_IMPORT.md](./AGENT_IMPORT.md)。

## 历史：Vertex 原始整包恢复验证

本机 gcloud 凭据通过隔离 Node 代理访问 Vertex Gemini 4 Argon。浏览器继续运行同一 Agent 与工具，OAuth token 不下发浏览器，不改变生产模型顺序。

- 结果：18 人、403 条课程方案、18 份逐人来源自查；23 个内部文件全部标记完成，未读为 0，最终状态 `review`。
- 对照：18 人全部通过身份、部门、无时段课程及课程时段比较；5,241/5,241 个已标注事实匹配，无额外/重复占用。对照仍是开发 Agent 独立转录，非操作员验收。
- 标注纠正：独立回看一份 App 原图后，发现两个课程名实际上以省略号截断，原标注擅自补全了名称；已改回可见原文并保留纠正理由，星期/周次/节次未改。
- 边界：两次请求达到 90 秒时限，原样重试仍失败；修复为持久化小批输出引导后恢复。随后大图请求超过 20 MiB，加入传输图片预算后恢复。总任务年龄 2,248.067 秒包含中断与修复间隔，不能称为单次性能成绩。三段执行耗时分别为 1,406.209、395.302、216.089 秒。
- 未正式提交：18 份方案缺少完整确认的学期/作息绑定。姓名冲突、单周截图、遮挡及未排时段课程保留待确认；不能为了通过校验生成材料不支持的上下课时刻。

- 黄振鹤：目录提供姓名线索，但图中姓名为李墨。这轮另外保存黄振鹤的零课程待确认方案，明确缺少本人课表；没有把李墨课程复制给他。该推断仍需人工确认，不计作第 19 份已识别课表。

- 两段实际执行 1,244.940 + 775.148 = **2,020.088 秒（约 33 分 40 秒）**；任务年龄 2,094.475 秒包含修复间隔。107 次模型请求累计 1,928.075 秒（约 95.4%），输出 77,357 tokens。第一轮三段执行合计 2,017.600 秒，因此没有证据证明整包速度已明显提升。
- 第二轮没有再次出现图片请求过大。大图传输预算保留全部来源图片，超预算预览压缩，原件不变。

两轮均未写入正式业务库。尚缺可信完整作息与学期绑定，不得把课程方案已识别等同于正式导入条件齐备。上述事实对照覆盖这份材料，不证明其他压缩包或生产模型顺序下同样准确。

## 本轮已修复并覆盖回归的缺陷

- 识别成果结构化保存，不因缺少学期或作息只留下人员及空周历。
- 保留交接前的材料成果、工具记录与必要原图，参数错误反馈给 Agent 修正。
- 同一 Agent 聚焦逐人回看来源，工具范围与当前阶段一致；已核对状态优先于旧摘要。
- 表格末列、文本分段、表外附注、图片区域采用实际覆盖校验；新增分块区域计入进展。
- 原件读取结果不再被统一预览截断，避免“覆盖已读完、模型没收到尾部证据”。
- 旧 XLS 的 GBK/HTML 文本与合并单元格读取、表格安全网格渲染、图片裁剪边界与单页语义。
- 显式课程索引、可操作的更新/删除冲突反馈；空 entries 不能覆盖已保存课程。
- 已知额度耗尽脱敏呈现，不立即重复请求；短期 Retry-After 与通用 503 区别处理。
- 原生 Responses 协议可通过显式参数启用，使用现有 SDK；凭据不下发浏览器。

本地 typecheck、131 项测试、28 项浏览器测试与生产构建通过。构建仍有现有大 chunk 提示。自动化回归覆盖执行器恢复、工具契约、来源读取、草稿隔离与人工审核门槛。这些测试不能替代上面的真实模型识别比较。

- 新增日历证据草稿：部分日期与钟点可持久保存、直接复核编辑；总周数与最低已知周数分开，完整后生成并绑定实际占用。
- 核对契约包含身份、课程时段、教师地点、日历及原件完整性，逐项索引必须覆盖当前方案。随后全批协调，交付统计由草稿生成。
- 明确无固定时段的课程保存独立课程及个人选课；未知时段继续阻止正式提交。审核通过的结构化记录与业务数据同事务持久保存。
- Google 视觉请求显式使用 HIGH 媒体分辨率。原生无效工具响应和截断输出分类后，可带纠正指令重试一次；配置错误和内容过滤不按此重试。
