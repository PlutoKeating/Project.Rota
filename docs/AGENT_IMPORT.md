# 浏览器本地 Agent 导入

## 用户流程

导入页只有统一材料入口。可拖入 ZIP / RAR / 7z / TAR / GZ、单文件或多文件，无需选择人员、文件类型、学期或部门。一次选择最多 100 MiB，面向约 100 人、500 份材料；解包工具限制每包 500 MiB / 1000 文件，整批材料最多 600 MiB / 1500 文件，嵌套最多 8 层。超过限制明确报错，不静默丢文件。

Agent 自主读取目录、文件名、说明、文本、表格和图片；自主查询已有数据并操作隔离草稿。基础库只处理文件格式，不能依据固定表头、人名正则或模板生成业务数据。Agent 不联网、不执行任意代码或 SQL；只能调用注册工具。模型按后台全局顺序选用支持视觉及工具调用的配置，失败尝试下一项，密钥始终由 Cloudflare Worker 持有。

整理后按组织树展示人员、独立课表、学期/作息、任务与班次，附来源、推断和删改对照。操作员可直接改字段，也可提供自然语言意见继续处理。默认整批确认；可以排除部分人员的变更，剩余内容仍须通过关系校验。正式数据仅在明确点击审核确认后原子写入。

## 执行位置与持久化

- TypeScript 浏览器循环：选择工具、执行本地动作、保存结果、继续模型调用。
- Web Worker：7-Zip WASM、SheetJS、Mammoth、JSZip、MS-DOC/PPT 格式库。工具有 90 秒超时，超时终止对应 Worker。
- PDF.js 和 Canvas：PDF 页与图片读取、裁剪、缩放，图片交给视觉模型。
- IndexedDB：原件、派生图片、草稿、来源、笔记、对话、待执行工具和日志。按管理员 ID 区分批次列表；这是同源本机存储，不是设备级加密隔离。
- Cloudflare Worker：单轮模型协议适配及凭据代理、鉴权、读取业务快照、租约与最终提交校验。
- ECS：沿用现有 SQLite 数据持久化与事务服务。没有 Agent 进程、文档转换服务或解包任务，没有新增计算容器。

连续 8 次工具失败会暂停保留进度，避免无效循环消耗。每轮响应先保存待调用列表，再顺序执行工具并保存结果。刷新或关闭页面会中断运行，重新打开原浏览器可恢复。Web Locks 防止同批次在多个标签页同时运行。上下文交接只在没有未完成工具调用的边界发生：先由同一 Agent 生成交接摘要并归档完整文字历史，再替换活动上下文；失败则保留原上下文暂停。完整草稿、证据、逐材料识别成果和工作笔记保留在本地。原始材料不自动上传到文件服务，只把模型当前需要的文字/图片经凭据代理发送给选定供应商。

**完成或取消后保留 8 小时**。应用打开时和导入页运行期间清理已过期批次与文件；浏览器关闭时无法执行定时任务，到期材料下次打开时清理。未完成草稿保留到处理完成或取消。用户也可以对已完成/取消批次立即清理。本地存储受浏览器配额、隐私模式、用户清除站点数据影响；浏览器数据丢失后不能恢复原件。正式库批次关联与审计长期保留，不含原件或对话。

## 工具与提示词

契约及 system prompt：`src/shared/agent-import/tools.ts`。

- `tree` / `unpack`：查看目录与按需逐层解包。
- `read_document` / `view_image`：分页、分段、工作表/范围读取、原图/PDF 页及裁剪。
- `describe_entity` / `query_records` / `change_record`：完整实体契约及草稿 CRUD，覆盖组织、人员、角色、部门关系、学期、节次、作息、独立课表、历史课程、选课、不可用时段、任务、班次和安排。
- `observe_material` / `read_observations`：逐材料保存识别事实与未确定项，不依赖已创建学期或作息；两份已读材料尚未保存成果时，阻止继续读取第三份新材料。
- `read_history`：分页检索完整工具参数、结果和交接历史；大结果在活动对话中保留摘要与检索键。
- `save_handoff`：仅在交接模式开放，不混入普通业务工具。
- `note` / `read_notes` / `mark_file`：工作记忆与材料覆盖记录；未读取材料不能标记处理完毕。
- `validate_draft` / `finish_review`：结构校验、自查与交付人工复核，均无正式提交权限。

提示词要求查证同名身份、保留多部门关系、每人独立课表、不捏造缺失学号/日期/时间、显示推断与冲突，继续完成可处理部分后集中报告缺项。上传内容作为数据而不是指令，不能改变工具权限。Agent 的自查和结构校验不能证明识别绝对无误；人工复核是最终步骤。

## 文档读取边界

- XLSX / XLS / CSV：单元格坐标、格式化值、公式、样式、批注、合并区域；超过范围分页，不猜业务表头。
- DOCX：正文文本、包内 XML、内嵌图片；PPTX：幻灯片/备注文本、页 XML、图片。
- DOC / PPT：浏览器原生格式库返回结构化块/幻灯片与图片。
- PDF：逐页渲染给视觉模型；图片支持裁剪并放大。
- 文本：支持 UTF-8、GB18030、UTF-16LE；无扩展名的文本也可阅读。
- 无扩展名的 Office/PDF/常用图片通过容器/文件头识别，不据此推断业务含义。

转换/文本读取不承诺完整重现 Office 字体与复杂版式；低清图片也无法凭空还原信息。工具错误、无法读取、缺密码或不支持内容必须留在复核结果，不能视为无课程。ZIP 嵌套、合成 DOC/DOCX/PPT/PPTX/XLS/XLSX/CSV/PDF/PNG 已有浏览器验证；不声称所有历史变体、加密方式和损坏文件均可读。

## 业务数据与提交

`schema/rota.yaml` 增加人员班级/专业，以及 `TimetableProfile`、`TimetableEntry`、`TimetableEvent`。增量迁移 `0005_browser_agent_import.sql` 另外维护批次、锁、提交断言及修订号等运行时表。

- 独立课表以个人为单位，关联学期与作息，明确周次/星期/节次；展开成真实时间段。支持同学期多套作息。
- 全局节次保留，已有共享课程兼容。新独立课表在可用性网格中按时间重叠标记，排班额外按绝对时间查询，因此全局节次以外的晚课同样阻止派班。
- 未识别出占用的时间按空闲；资料不完整必须在复核时提示。
- 已有人员与部门关系默认保留；空学号允许。新增或修改的数据都要附来源及推断标记。
- 人员页的独立课表入口支持修正与删除；通过同一校验/事务路径提交。没有“撤销整个导入批次”功能。

浏览器上传结构化差异而非 SQL。服务端阻止新增约束冲突，已有历史问题不阻塞无关导入；重新校验字段白名单、原值、外键、重复记录、学期/周次/节次和班次冲突；生成 SQL 仅来自共享实体契约。原子提交包括业务变更、派生占用、必要的公平投影、批次关联和审计。批次内容哈希保证重复确认幂等，失败全部回滚。

相关实体及依赖项使用 180 秒租约；工作界面每 45 秒续期，事务触发器也约束普通 CRUD 路径。租约过期后释放；恢复时重新读取快照，冲突变更交由 Agent 重新协调。共享学期等实体的依赖闭包可能锁定较多记录，以保护现有引用。提交在同一事务内复核修订号和全部租约，避免校验与写入之间的数据变化。

## 验证

- `pnpm check`：类型、真实 SQLite 的原子性/并发锁/幂等/多作息冲突/100 人批次与模型协议测试，以及原有测试。
- `pnpm build`：前端、文档 Worker、WASM、PDF Worker 与 API 构建。
- `pnpm test:agent-browser`：独立静态测试服务，API 全部拦截，不访问生产；真实浏览器文件工具、刷新恢复、审核边界、格式读取与 8 小时清理测试。
- `test/fixtures/import` 全为合成材料，无真实人员资料。LibreOffice 仅用于生成旧格式测试样本，不是产品运行依赖。

没有在测试中调用真实付费供应商或提交生产业务数据；模型识别质量仍需用经授权的真实材料和实际配置模型验收。

## 随包许可

`public/licenses/agent-import` 包含文件读取库与模型 SDK 的许可及来源，随静态站点发布。7z-wasm 使用 LGPL 与 unRAR 附加限制，未修改其分发代码；WASM 保持独立可替换资源，来源与构建说明见随包 README。

SQL 批事务在提交时校验外键（`defer_foreign_keys`），允许同批新增上级、迁移子记录及删除旧上级；最终悬空引用仍使整个事务回滚。

## 长任务稳定性与选型依据（2026-11-04）

实测日志出现数十分钟重复读取、反复查询实体契约、仅产生一条学期草稿。旧执行器用 `slice(-12)` 截断消息后再删除开头 assistant/tool，可能清空有效识别上下文；保留原件并不等于保留识别成果。这是本次修复的主要根因。503 的真实上游来源无法仅凭旧日志追溯，旧客户端将所有 503 指向迁移的提示没有证据支持。

研究后保留已有 AI SDK 协议适配与浏览器执行边界，没有换成服务端 Agent：

- [Anthropic 长任务 harness](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents)：借鉴增量成果、可恢复工作状态和交接机制。
- [Anthropic 上下文工程](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)：借鉴压缩、结构化笔记与按需检索，避免无限堆叠工具输出。
- [Deep Agents summarization 实现](https://github.com/langchain-ai/deepagents/blob/main/libs/deepagents/deepagents/middleware/summarization.py)：借鉴完整历史外置、摘要留在活动上下文的设计；不直接引入 Python 服务。
- [Deep Agents JS 浏览器兼容性讨论](https://github.com/langchain-ai/deepagentsjs/issues/834)：存在浏览器运行时适配问题报告，不能假设更换框架就自动满足本项目浏览器边界；本次复用已验证的协议适配层。
- [Pi compaction 文档](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/compaction.md)：参考持久交接与恢复信息，而非简单删除历史消息。
- [AI SDK 调用设置](https://ai-sdk.dev/docs/ai-sdk-core/settings)：继续使用现有供应商协议、工具 schema、usage 与取消信号；执行期限与重试边界由本项目显式控制。

具体机制：

1. 原 `rota-agent-import` 数据库版本不变，兼容既有批次。新增 `rota-agent-history` 数据库承载完整文字历史，避免旧标签页阻塞原数据库升级。草稿与待归档检查点先原子保存，归档按键幂等；恢复时重放未归档检查点。历史按批次/时间游标分页，不每次载入所有历史。
2. 每份材料用 `observe_material` 保存来源关联的识别事实和未确定项。读取不等于完成；标记完成前需保存未记录的识别成果。缺少日期/作息仍能保存事实并继续其他人员，不能根据最大课程周次伪造总周数或首周日期。
3. 活动文字约 48,000 字符或消息超过 100 条时，在工具调用完整边界进行交接。摘要和完整历史归档成功才收缩上下文。超过 12,000 字符的工具结果外置，模型可按 key/offset 读全文。交接摘要不会代替原件或持久识别成果。
4. 图片供下一次成功模型响应使用，随后用来源引用替换历史中的图片字节；原件仍可裁剪重读。默认图像缩放改为 1，避免无意义的 1.5 倍放大；PDF 初始页面渲染仍保留 1.5 倍。尚未得到模型响应的图片不提前清除。
5. 连续 6 轮没有新增草稿、识别成果或文件覆盖进度时注入纠偏提示，12 轮暂停并保留工作。仅成功执行查询不算进展；连续 8 次工具错误仍暂停。模型可在结构问题无法解决时交付问题清单，复核界面和最终提交校验继续阻止不合法草稿入库。
6. 每批成功供应商优先复用；失败项短暂冷却。记录真实模型 ID、各次尝试耗时/HTTP 类别、tokens 与请求编号。进度区显示当前阶段和等待秒数；展开后可查看识别成果与完整工具历史。最近 200 次请求诊断随草稿保存，完整模型/工具/失败请求历史另行归档。工具记录包含参数、全文结果和执行耗时，不仅展示截断片段。
7. 原件、识别成果、交接、历史和诊断均随完成/取消批次在 8 小时到期后清理；关闭浏览器期间到期，下次打开清理。未完成草稿不因升级清空。旧版本已经截掉且没有保存的事实无法恢复，只能重新核对来源。

### 验证边界

`pnpm test:agent-browser` 覆盖真实 Chromium + IndexedDB + 本地工具：30 份合成材料、多次交接、刷新恢复、全文历史检索、交接失败不丢上下文、未归档检查点恢复、停滞暂停、两份材料写入保护、503 有界重试，以及有结构问题的草稿能复核但不能提交。模型输出为受控响应，测试执行器恢复与隔离，不证明真实模型能够无误识别所有课程。现有旧 Office / PDF / 图片 / 嵌套压缩包工具测试继续保留。

没有新增运行依赖、环境变量或数据库业务迁移；浏览器专项测试配置显式设置仓库根目录为工作目录，可直接从项目脚本启动。发布仍需要前端与 Worker 同版本；不能只更新前端就使用新的交接工具协议。真实批次识别质量、供应商速度和该次 503 的具体来源需要新版运行日志验收，不将合成测试结果当作生产成功证明。
