# 交付进度

## 已实现

- 学期、节次、课程、人员组织、任务、班次、排班、公平统计、结构化课表导入与 CSV 导出。
- OIDC 授权码 + PKCE、nonce/state、JWKS 签名验证、服务端会话、CSRF 和 owner/admin 权限。
- 所有者维护管理员白名单；审计中使用登录账号。

- 无校历格子的有效班次仍可分配；跨周结转和重复并发撤销已补回归测试。
- 导入整单事务、历史公平计数、账本原子重算。
- HTTPS 文件存储适配器及 Workers AI 支持。
